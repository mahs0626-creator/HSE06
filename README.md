# HSE Academy — HSE05

A bilingual Persian/English HSE learning app starter built with Flutter.

## First release scope
- Course catalogue and lesson reader
- English learning text with Persian explanation
- Multiple-choice knowledge checks
- Local lesson completion and quiz progress
- GitHub Actions workflow to build a release APK

## Build
The workflow creates the standard Android platform files if they are missing, runs `flutter pub get`, analyzes `lib/`, builds a release APK, and uploads it as the `HSE05-APK` artifact.

> Training content is educational. Always verify legal requirements against current official OSHA sources. This app is not an OSHA Outreach Training provider and does not issue OSHA cards.
